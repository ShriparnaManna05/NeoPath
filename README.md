# NeoPath - Career Guidance Platform

**Reinventing the Career Journey**

NeoPath is a comprehensive career guidance platform that connects students with professional counsellors to help them discover their true potential and make informed career decisions.

## 🌟 Features

### For Students
- **Secure Registration & Login**: Create and manage your account with ease
- **Profile Management**: Update personal information, skills, and career interests
- **Comprehensive Assessments**: Take aptitude, personality, and skill tests
- **Assessment Results**: View detailed results with pass/fail status and scores
- **Career Path Suggestions**: Receive personalized career recommendations
- **Session Booking**: Schedule one-to-one sessions with counsellors (video/chat/offline)
- **Progress Tracking**: Monitor your career development journey

### For Counsellors
- **Professional Profiles**: Manage qualifications, experience, and specialties
- **Session Management**: Conduct one-to-one and group counselling sessions
- **Student Guidance**: Provide career path suggestions and mentorship
- **Mentoring Program**: Mentor other counsellors in a unary relationship
- **Performance Analytics**: Track session success and student feedback

### For Administrators
- **User Management**: Manage students, counsellors, and system users
- **Comprehensive Reports**: Generate detailed analytics on:
  - Assessment performance
  - Counsellor activity
  - Career paths suggested
  - Platform usage statistics
- **Resource Portal**: Maintain and manage career resources
- **System Settings**: Configure platform settings and preferences

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No additional software installation required

### Installation
1. Clone or download the project files
2. Open `index.html` in your web browser
3. Start exploring the platform!

### Quick Start Guide
1. **Visit the Homepage**: Open `index.html` to see the NeoPath landing page
2. **Register**: Click "Register" to create a new account
3. **Choose User Type**: Select Student, Counsellor, or Administrator
4. **Login**: Use your credentials to access your dashboard
5. **Explore Features**: Navigate through the platform using the sidebar menu
